    What you need to do

    1. Set CONTRACT VALUE (amount for the next invoice) 2. LOAD NEXT CONTRACT deploys a fresh Escrow, re-points gateway 3. START brings up Anvil - gateway - bouncer in order 4. Watch Panel 1 / 3 RF comms live; chain logs settlements 5. SEND ACK operator authorises the buyer payment 6. VIEW RECEIPTS read-only tail of receipts.json 7. STOP / EXIT graceful halt of run / whole stack

    Panels

    1. RF Comms (Ground ↔ Sat) — everything sent over the radio: ground-station radio ↔ satellite Heltecs. Invoice (A), Payment (B), ACK, Receipt (C), Delivery (D), Heartbeat (HB) all appear here. 2. Go Server (Gateway) — gateway health, verify counters, HTTP request log. 3. L2 Blockchain (Anvil) — mined blocks, settleBatch txs, SettlementCreated events; newest at bottom. 4. Operator Controls — the demo lifecycle lives here: load, start, stop.

    Leg states

    [IDLE] no activity yet [ACTIVE] leg currently in progress [OK] leg completed successfully [FAIL] CRC or signature failed — resets the pass counter

    Gate (bottom of Panel 1)

    Passes 10/10 · Tamper rejects visible · Restart-safe: a full demo pass is one clean A → B → ACK → SETTLE → C → D run. 10 consecutive passes = flat-sat alpha done.
